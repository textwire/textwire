# Release notes V6

## v6.0.0 (2026-11-06)

- ✨ `loop` object scope is now relative to the current loop instead of belonging only to a parent. If you want to get parent loop object use `loop.parent`. Closes [#138](https://codeberg.org/textwire/textwire/issues/138).
